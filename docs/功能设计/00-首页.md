> 当前实现基线：2026-09-02
>
> 本目录描述当前源码已经实现的用户能力、运行边界和核心数据流。实现与设计不一致时，以代码和测试为准，并在本文档中补充状态说明。

## 一、系统定位

CodeMate 是一个面向本地项目的编程 Agent：用户通过 Web UI 提交任务，Agent 使用 LLM 的流式 tool calling 读取和修改当前 Lane 工作目录、执行命令、搜索代码，并把过程实时反馈到会话工作台。

CodeMate 的核心差异不是单纯聊天，而是把两种状态同时保留下来：

1. **树形对话历史**：每条 message 是一个 Entry，`parent` 指针形成可回溯、可分叉的对话树。
2. **Lane 分支**：Lane 指向对话树叶子；Git 可用时还绑定独立代码状态、检查点和 Worktree。
3. **工作区分级管理**：`Workspace → Session → Lane` 把项目目录、一次会话和一次方案实验分开管理。

## 三、技术架构

```text
┌────────────────────────────────────────────────────────────┐
│ React 18 + TypeScript + Zustand + React Flow + Tailwind    │
│ Session Picker / Workbench / Conversation / Source Control │
└───────────────────┬───────────────────────┬────────────────┘
                    │ REST                  │ WebSocket
┌───────────────────▼───────────────────────▼────────────────┐
│ FastAPI API / SessionRuntime / WebSocket event dispatcher   │
├────────────────────────────────────────────────────────────┤
│ Agent Loop │ ToolRegistry │ LLMClient │ Memory │ Permission │
│ Naming     │ SubAgent     │ GitLaneManager │ Terminal       │
├────────────────────────────────────────────────────────────┤
│ WorkspaceStorage │ SessionStorage │ LaneManager │ JSON/JSONL│
└────────────────────────────────────────────────────────────┘
```

后端入口是 `backend/main.py`；REST 路由位于 `backend/src/api/routes.py`，WebSocket 位于 `backend/src/api/ws.py`。前端入口是 `web-ui/src/main.tsx`，进入工作台后的总布局位于 `web-ui/src/components/Workspace.tsx`。

## 五、最重要的数据流

### 5.1 创建并进入会话

Session Picker 先加载 Workspace 列表。用户可以使用原生目录选择器选择本地目录，创建或复用 Workspace，再在其中创建或打开 Session。进入后前端获取 Session 快照，再建立 WebSocket；快照负责全量历史，事件负责增量更新。

### 5.2 一次 Agent Run

用户提交消息后，前端先显示临时用户气泡，再通过 WebSocket 发送 `send_message`。SessionRuntime 为当前 Lane 构建 Agent：解析当前 Lane 工作目录、加载项目上下文和历史窗口、注册工具和权限管理器，然后执行 LLM → 工具 → 结果回填循环。结束后写入 Entry、推进 Lane 指针、推送运行结果；Git 启用时还会根据检查点策略记录代码状态。

### 5.3 切换 Lane

切换操作同时改变对话历史叶子和 Agent 的工作目录。前端刷新 Session 快照、文件树和源代码管理状态；历史视图按新的叶子计算路径。Git 不可用时只切换对话指针并明确能力降级。

## 六、明确的当前边界

- 编辑器只支持已有文本文件的读取和保存，不提供完整 IDE 语言服务。
- 终端是当前 Session WebSocket 上的受限交互进程，不是远程终端平台。
- Source Control 不是完整 Git 客户端，不提供远程推送、rebase、cherry-pick 和冲突编辑器。
- 子 Agent 的中间历史不写入父 Session 树，只通过进度事件和摘要返回。
- 结构化日志用于后端诊断，前端展示实时事件，不提供独立日志检索页面。
- 本系统不引入 Docker 容器沙箱，安全边界由权限门禁、路径检查、参数化进程和超时共同构成。
